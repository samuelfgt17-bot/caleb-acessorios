# Caleb Acessórios

Site em Vite + React, com 10 fotos reais e logo original.

## Executar

`npm install`

`npm run dev`

## Produção

`npm run build`

`npm run preview`

O resultado é gerado em `dist/`.

## Atualizar informações

Edite `src/config.js`. Confirmar endereço completo, horários, link do Google Maps e se o telefone atende pelo WhatsApp. Os campos pendentes estão ocultos. `whatsappConfirmed: true` ativa os botões de WhatsApp. A avaliação é referência da captura enviada; desative em `review.enabled` ou atualize após confirmação.

As imagens otimizadas estão em `public/images`, e os originais preservados em `originals`. A galeria usa diálogo nativo, foco restaurado, Escape e setas. Nenhum formulário coleta dados.
